# React SPA Application

SPA-приложение на React с использованием библиотеки компонентов Bootstrap для стилизации и разработки интерактивного пользовательского интерфейса.

## Использованные библиотеки

### Основные библиотеки
- **React** (^18.2.0) - библиотека для создания пользовательских интерфейсов
- **React DOM** (^18.2.0) - рендеринг React компонентов в DOM
- **React Router DOM** (^7.13.0) - маршрутизация для SPA приложений
- **React Scripts** (^5.0.1) - инструменты для разработки React приложений

### Библиотеки компонентов
- **Bootstrap** (^5.x) - CSS фреймворк для создания адаптивных интерфейсов
- **React Bootstrap** (^2.x) - React компоненты на основе Bootstrap

### Дополнительные библиотеки
- **React Icons** - коллекция популярных иконок для React
- **React Toastify** - библиотека для отображения уведомлений (toast)
- **Redux Toolkit (@reduxjs/toolkit)** - официальный инструментарий для эффективной разработки Redux
- **React Redux** - официальные React биндинги для Redux

## Redux Store

### Структура хранилища
Приложение использует Redux Toolkit для управления состоянием. Хранилище состоит из двух основных слайсов:

#### 1. PostsSlice (`src/store/slices/postsSlice.js`)
Управление состоянием постов с полным CRUD функционалом:
- **Create** - `addPost` - создание нового поста с валидацией
- **Read** - `fetchPosts` - загрузка списка постов
- **Update** - `updatePost` - обновление существующего поста с валидацией
- **Delete** - `deletePost` - удаление поста

**Особенности:**
- Валидация данных перед созданием/обновлением
- Обработка ошибок с детальными сообщениями
- Состояния загрузки (loading)
- Отслеживание последнего действия (lastAction)

#### 2. UIStateSlice (`src/store/slices/uiStateSlice.js`)
Управление состоянием пользовательского интерфейса:
- **Темная тема** - переключение и сохранение в localStorage
- **Модальные окна** - управление открытием/закрытием
- **Сайдбар** - управление видимостью
- **Уведомления** - система внутренних уведомлений
- **Состояние загрузки** - глобальный индикатор загрузки

**Особенности:**
- Валидация UI состояния
- Интеграция с localStorage для сохранения настроек
- Обработка ошибок UI операций

### Redux Actions

#### PostsSlice Actions:
- `fetchPosts()` - асинхронная загрузка постов
- `addPost(postData)` - добавление поста с валидацией
- `updatePost({ id, postData })` - обновление поста с валидацией
- `deletePost(id)` - удаление поста
- `clearError()` - очистка ошибок
- `clearLastAction()` - очистка последнего действия

#### UIStateSlice Actions:
- `toggleDarkMode()` - переключение темы
- `setDarkMode(boolean)` - установка темы
- `openModal({ type, itemId })` - открытие модального окна
- `closeModal()` - закрытие модального окна
- `toggleSidebar()` - переключение сайдбара
- `setSidebarOpen(boolean)` - установка состояния сайдбара
- `setLoading(boolean)` - установка состояния загрузки
- `addNotification({ message, type, id })` - добавление уведомления
- `removeNotification(id)` - удаление уведомления
- `clearNotifications()` - очистка всех уведомлений
- `clearError()` - очистка ошибок
- `resetUIState()` - сброс UI состояния
