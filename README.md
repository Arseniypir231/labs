# React SPA Application

SPA-приложение на React с использованием библиотеки компонентов Bootstrap для стилизации и разработки интерактивного пользовательского интерфейса.

## Использованные библиотеки

### Основные библиотеки
- **React** (^18.2.0) - библиотека для создания пользовательских интерфейсов
- **React DOM** (^18.2.0) - рендеринг React компонентов в DOM
- **React Router DOM** (^7.13.0) - маршрутизация для SPA приложений
- **React Scripts** (^5.0.1) - инструменты для разработки React приложений

### Библиотеки компонентов
- **Bootstrap** (^5.x) - CSS фреймворк для создания адаптивных интерфейсов
- **React Bootstrap** (^2.x) - React компоненты на основе Bootstrap

### Дополнительные библиотеки
- **React Icons** - коллекция популярных иконок для React
- **React Toastify** - библиотека для отображения уведомлений (toast)

## Использованные компоненты Bootstrap

### Компоненты навигации
- **Navbar** - навигационная панель в шапке сайта
- **Nav** - компонент навигации
- **Nav.Link** - ссылки навигации
- **Pagination** - компонент пагинации

### Компоненты макета
- **Container** - контейнер для контента
- **Row** - строка сетки Bootstrap
- **Col** - колонка сетки Bootstrap

### Компоненты контента
- **Card** - карточка для отображения контента
- **Card.Body** - тело карточки
- **Card.Header** - заголовок карточки
- **Card.Title** - заголовок внутри карточки
- **Card.Text** - текст внутри карточки
- **Card.Img** - изображение в карточке
- **Image** - компонент изображения
- **Badge** - бейдж для меток и категорий
- **Alert** - компонент уведомлений

### Компоненты форм
- **Form** - компонент формы
- **Form.Group** - группа полей формы
- **Form.Control** - поле ввода формы
- **Form.Label** - метка поля формы
- **Form.Select** - выпадающий список формы
- **Form.Check** - чекбокс формы
- **InputGroup** - группа полей ввода
- **InputGroup.Text** - текст в группе ввода

### Компоненты кнопок
- **Button** - кнопка
- **ButtonGroup** - группа кнопок

### Компоненты модальных окон
- **Modal** - модальное окно
- **Modal.Header** - заголовок модального окна
- **Modal.Body** - тело модального окна
- **Modal.Footer** - подвал модального окна
- **Modal.Title** - заголовок модального окна

### Компоненты списков
- **ListGroup** - группа списка
- **ListGroup.Item** - элемент списка

### Компоненты вкладок
- **Tabs** - компонент вкладок
- **Tab** - отдельная вкладка

### Компоненты вспомогательные
- **OverlayTrigger** - триггер для всплывающих элементов
- **Tooltip** - всплывающая подсказка
- **Spinner** - индикатор загрузки

## Структура проекта

```
src/
├── components/          # React компоненты
│   ├── Header.js       # Шапка сайта с навигацией
│   ├── Footer.js       # Подвал сайта
│   ├── Hero.js         # Главный баннер
│   ├── PostCard.js     # Карточка поста
│   ├── PostsSection.js # Секция с постами
│   ├── Sidebar.js      # Боковая панель
│   ├── ManagementPanel.js # Панель управления
│   ├── Pagination.js   # Пагинация
│   ├── InstagramWidget.js # Виджет Instagram
│   ├── PostDetailModal.js # Модальное окно деталей поста
│   ├── PostFormModal.js # Модальное окно формы поста
│   └── ThemeToggle.js  # Переключатель темы
├── pages/               # Страницы приложения
│   ├── Home.js         # Главная страница
│   ├── Recipes.js      # Страница рецептов
│   ├── Article.js      # Страница статей
│   ├── Contact.js      # Страница контактов
│   ├── Search.js       # Страница поиска
│   ├── Favorites.js    # Страница избранного
│   └── About.js        # Страница "О нас"
├── context/            # React Context
│   └── AppContext.js   # Глобальный контекст приложения
├── data/               # JSON данные
└── App.js              # Главный компонент приложения
```

## Функциональность

### Основные функции
- ✅ Отображение постов, статей и рецептов
- ✅ Управление контентом (добавление, редактирование, удаление)
- ✅ Модальные окна для просмотра и редактирования
- ✅ Адаптивная верстка (320px - 1920px)

### Дополнительные функции
- 🔍 **Поиск** - поиск по постам, статьям и рецептам с фильтрацией и сортировкой
- ⭐ **Избранное** - сохранение понравившихся элементов
- 🌙 **Темная тема** - переключение между светлой и темной темой
- 🔔 **Уведомления** - toast-уведомления о действиях пользователя

## Установка и запуск

```bash
# Установка зависимостей
npm install

# Запуск приложения в режиме разработки
npm start

# Сборка для продакшена
npm run build
```

## Требования

- Node.js (версия 14 или выше)
- npm или yarn

## Особенности

- Использовано более 25 различных компонентов Bootstrap
- Полностью адаптивный дизайн
- Использование относительных единиц измерения (rem, em, %)
- Интерактивные элементы с hover-эффектами и анимациями
- SPA-приложение с клиентской маршрутизацией
