# Transport Logistics - React Client

Клиентская часть веб-приложения для управления транспортной логистикой.

## Технологии

- **React 18** - библиотека для создания пользовательских интерфейсов
- **Redux Toolkit** - управление состоянием приложения
- **React Router** - маршрутизация
- **Axios** - HTTP-клиент для работы с API
- **React Hook Form** - управление формами и валидация
- **React Toastify** - уведомления
- **Vite** - сборщик и dev-сервер

## Установка

```bash
npm install
```

## Запуск

```bash
npm run dev
```

Приложение будет доступно по адресу `http://localhost:3001`

## Сборка для продакшена

```bash
npm run build
```

Собранные файлы будут в папке `dist/`

## Функциональность

- ✅ Адаптивный интерфейс
- ✅ Redux для state management
- ✅ Роутинг между страницами
- ✅ CRUD операции для всех сущностей
- ✅ Формы с валидацией
- ✅ Пагинация, сортировка, фильтрация, поиск
- ✅ Детальные страницы с фото
- ✅ Подтверждение удаления
- ✅ Уведомления об операциях
- ✅ Загрузка фото
