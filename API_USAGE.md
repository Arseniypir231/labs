# Использование API Frontend

## Структура проекта

Проект соответствует требованиям структуры:

- **`server/app.js`** - Express сервер
- **`public/api-demo.html`** - HTML страница с фронтенд-кодом
- **`public/api-demo.js`** - JavaScript файл для работы с API
- **`server/data/posts.json`** - JSON файл с данными постов
- **`server/routes/posts.js`** - Роуты для работы с постами
- **`server/routes/data.js`** - Роут с поддержкой Accept заголовка
- **`server/utils/fileUtils.js`** - Утилиты для работы с файлами

## Запуск

1. Запустите сервер:
```bash
npm run server
```

2. Откройте в браузере:
```
http://localhost:3001/api-demo.html
```

## Функциональность

### 1. Получение данных (GET)
- **Загрузить все посты** - кнопка загружает все посты с сервера
- **Загрузить пост по ID** - загрузка конкретного поста по ID
- Данные отображаются в виде карточек постов

### 2. Поиск постов (POST)
- Поиск по тексту запроса
- Фильтрация по категории (выпадающий список)
- Фильтрация по автору
- Результаты отображаются в отдельной секции

### 3. Создание поста (POST)
- Форма для создания нового поста
- Обязательные поля: изображение, категория, заголовок, дата, автор
- Опциональные поля: комментарии, описание
- После создания пост автоматически добавляется в список

### 4. Удаление поста (DELETE)
- Удаление поста по ID через форму
- Удаление поста из карточки (кнопка "Удалить")
- Подтверждение перед удалением

### 5. Скачивание данных
- **Скачать JSON** - скачивает данные в формате JSON
- **Скачать XML** - скачивает данные в формате XML
- **Скачать HTML** - скачивает данные в формате HTML
- Формат определяется заголовком Accept

## События и обновления

- При создании поста список автоматически обновляется
- При удалении поста список автоматически обновляется
- Все действия показывают сообщения об успехе/ошибке
- Данные отображаются в реальном времени

## API Endpoints

- `GET /api/posts` - получить все посты
- `GET /api/posts/:id` - получить пост по ID
- `POST /api/posts` - создать новый пост
- `POST /api/posts/search` - поиск постов
- `DELETE /api/posts/:id` - удалить пост
- `GET /api/data` - получить данные в формате JSON/XML/HTML
